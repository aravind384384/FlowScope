# Running a Basic Terminal Output Test

## Overview

This guide demonstrates how to execute a simple text command in Windows PowerShell to verify basic console output functionality.

## Step 1: Print Test String [EXECUTION]

Pass arguments to the `echo` command to print a test message to the standard output and confirm shell responsiveness.

```bash
echo Gemini test
```

Expected output:
```
Gemini
test
```

## Result

The test string was successfully evaluated and printed to the terminal console.
